# Graphics
To improve the three-dimensional impression there are some options. 
At the moment further settings can only be made in the viewer.
## Shadows
```cpp
use_shadows(true);
```


## Ambient Occlusion
```cpp
use_ambient_occlusion(true);
```

## Transparency
```cpp
use_transparency(true);
```

## Post Processing
```cpp
set_gamma(2.4);
set_saturation(1.0);
set_contrast(1.0);
```
